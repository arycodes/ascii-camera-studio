# ASCII Camera Studio

A real-time webcam to ASCII art converter built with HTML, CSS, and JavaScript.
**Live Demo:** [https://arycodes.github.io/ascii-camera-studio/](https://arycodes.github.io/ascii-camera-studio/)

## Features

* Live ASCII conversion from your webcam feed.
* Adjustable font size, line height, resolution, brightness, and contrast.
* Custom ASCII text colors and color palettes.
* Take snapshots of the ASCII output as a text file.
* Responsive design for different screen sizes.

## How to Use

1. Open `index.html` in your browser.
2. Allow webcam access when prompted.
3. Adjust settings (font, resolution, brightness, contrast, colors) as needed.
4. Take snapshots (obviously in text form) or reset settings using the buttons.

## Technologies

* HTML
* CSS
* JavaScript
